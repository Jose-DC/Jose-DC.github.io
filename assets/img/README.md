# Imágenes del portafolio

Carpeta para capturas, diagramas y evidencias visuales de los proyectos.

Sugerencia de orden: una subcarpeta por proyecto dentro de `proyectos/` (por ejemplo `proyectos/plataforma-docker-lab/`), reflejando el nombre del archivo HTML correspondiente.

Evita subir información sensible, tokens, correos privados, nombres de clientes, IPs internas o capturas con datos laborales confidenciales.
