# Portafolio técnico

Sitio web estático de José Díaz para presentar experiencia en soporte cloud, infraestructura TI, Azure/AKS, monitoreo, documentación y continuidad operativa, junto con proyectos documentados de Docker, Linux y automatización.

## Estado

- Publicado en: https://jose-dc.github.io/
- Base visual vigente: la versión publicada en GitHub Pages.
- Copia local: esta carpeta, usada para iterar antes de publicar.
- Alcance público: experiencia defendible, proyectos con estado explícito y aprendizaje técnico sin sobreventa.

El sitio no debe publicar nombres de clientes, arquitectura interna, URLs operacionales, credenciales, tokens ni capturas sin sanitizar.

## Estructura

- `index.html`: portada y presentación principal.
- `experiencia.html`: trayectoria profesional.
- `proyectos.html`: índice de proyectos.
- `proyectos/`: fichas individuales con alcance y evidencia.
- `assets/styles.css`: estilos compartidos.
- `assets/img/`: capturas, diagramas y evidencias sanitizadas.
